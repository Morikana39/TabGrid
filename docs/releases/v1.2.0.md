# TabGrid v1.2.0

[English](#release-en) · [简体中文](#release-zh-cn) · [日本語](#release-ja)

<a name="release-en"></a>

## English

- Display native split views as one card, with a shared context menu and a separate close button for each pane. Add grouping and Undo for split-view closure, grouping, and separation where Chrome supports restoration.
- Reorder split cards within a window by moving surrounding ordinary tabs or whole groups, preserving the pair. Continue dragging both panes from a group panel into the main grid.
- Use themed dropdowns for Pinned, Playing audio, and Muted filters. Restore click-again-to-close behavior and improve keyboard selection.
- Give Refresh and Update all thumbnails distinct icons. Soften press animations on wide disclosure rows and remove individual background blocks from glass context-menu items.

Download **TabGrid.zip** below. Extract it, open `chrome://extensions`, enable Developer mode, and select **Load unpacked** to choose the extracted folder containing `manifest.json`.

**Validation and limits:** 352 automated tests pass. The user-run native Chrome 157/macOS report passed eight split-reorder and grouping checks. Split-card movement between windows and crossing two ungrouped split pairs remain unavailable. Chrome does not expose split orientation or divider position; TabGrid does not offer layout/reverse controls for them. Native Windows visual testing and the physical hold-outside group-drag gesture remain unverified. Screenshot permissions for restricted pages remain controlled by Chrome.

## 简体中文

- 将原生分屏显示为一张卡片，共用右键菜单，每个分屏保留独立关闭按钮。支持分屏分组，并在 Chrome 支持恢复时为关闭、分组和拆分操作提供撤销。
- 通过移动周围的普通标签或整个标签组，在同一窗口内调整分屏卡片的位置并保持分屏配对。支持将两个分屏一起从标签组面板继续拖到主网格。
- 固定、正在播放音频和静音筛选器改用扩展主题下拉菜单。恢复再次点击关闭菜单的行为，并改进键盘选择。
- 为刷新和更新所有缩略图使用不同图标。减弱宽折叠行的按压动画，移除玻璃风格右键菜单项的独立背景块。

下载下方的 **TabGrid.zip** 并解压，打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压文件夹。

**验证与限制：** 352 项自动化测试通过。用户在 macOS 的原生 Chrome 157 中运行的报告通过了八项分屏排序和分组检查。暂不支持跨窗口移动分屏卡片，也不支持两个未分组分屏配对互相跨越。Chrome 未提供分屏方向或分隔位置接口，因此 TabGrid 不提供布局或反转控制。Windows 原生视觉表现和拖出标签组时的实际悬停手势尚未验证。受限页面的截图权限仍由 Chrome 控制。

## 日本語

- ネイティブ分割ビューを1枚のカードで表示し、共通のコンテキストメニューと各ペインの閉じるボタンを追加しました。グループ化に対応し、Chrome が復元をサポートする場合は、閉じる・グループ化・分割解除を元に戻せます。
- 周囲の通常タブやグループ全体を動かすことで、ペアを維持したまま同じウィンドウ内で分割カードを並べ替えます。グループパネルから両ペインをメイングリッドへ続けてドラッグできます。
- 固定・音声再生中・ミュートのフィルターにテーマ対応のドロップダウンを使用します。再クリックで閉じる動作とキーボード選択を改善しました。
- 更新とすべてのサムネイルを更新に別々のアイコンを使用します。幅の広い開閉行の押下アニメーションを控えめにし、ガラス風コンテキストメニューの各項目に付いていた背景を削除しました。

下の **TabGrid.zip** をダウンロードして展開し、`chrome://extensions` でデベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」から `manifest.json` を含むフォルダーを選んでください。

**検証と制限：** 352 件の自動テストを通過しました。ユーザーが macOS のネイティブ Chrome 157 で実行したレポートでは、分割カードの並べ替えとグループ化に関する8項目を通過しました。ウィンドウをまたぐ分割カードの移動と、グループ化されていない2つの分割ペアが互いを越える移動は未対応です。Chrome は分割方向や境界位置の API を提供していないため、レイアウトや左右反転の操作は提供していません。Windows のネイティブ表示と、グループ外で待機してドラッグを継続する実際のジェスチャーは未検証です。制限されたページのスクリーンショット権限は引き続き Chrome が管理します。
